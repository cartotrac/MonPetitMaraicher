Application

MonPetitProducteurLocal est une application web libre sous licence GNU AGPL-3.0, développée dans le dépôt public github.com/cartotrac/MonPetitMaraicher — le code source peut être consulté, réutilisé et adapté ; toute instance publique modifiée doit partager ses modifications.

Instance et éditeur

Cette instance du portail est exploitée par CartoTrac, responsable de son contenu et de l'animation des producteurs et clients qui y sont référencés. Contact : via la page de contact de l'exploitant ou à l'adresse indiquée sur le dépôt GitHub.

Les informations publiées sur les vitrines (productions, prix, disponibilités, points de livraison) relèvent de la responsabilité de chaque producteur.

Hébergement

L'application est hébergée par AlwaysData — alwaysdata.com (infrastructure située dans l'Union européenne), sur un serveur mutualisé avec base de données PostgreSQL.

Données personnelles

Seuls les éléments strictement nécessaires à la mise en relation producteur / client sont enregistrés : identité, coordonnées de contact et historique des commandes pour les comptes ; pour les commandes sans compte, l'identité de contact saisie au moment de la commande. Les photos et visuels sont hébergés par les producteurs eux-mêmes (liens externes) : le portail n'héberge aucun fichier envoyé par les clients. Aucune donnée n'est cédée à des tiers ; pour l'exercice de vos droits (accès, rectification, suppression), contactez l'exploitant de l'instance.
